# Роли админки, уровень 576–767 px (`sm:`), выведены из эталона 390 px

Вывод по правилу, а не по тому, что видно на экране. Эталон — таблица телефона (`admin-roles-mobile.md`). Для каждой роли задан шаг на 576+. Цвет, регистр и вес не меняются.

## Правила шагов
- Заголовки: +2 px (20 → 22).
- Названия строк и тексты-значения списков: +1 px (13 → 14).
- Основные кнопки (L): высота +4 (36 → 40), текст +1 (13 → 14).
- Поля, комбобоксы, дата: высота +4 (36 → 40), текст без изменения (14).
- Подписи, описания, пустые состояния, ошибки, бейджи, счётчик, метки: без изменения.
- Кнопки M, иконки в строке, кнопка «Назад»: без изменения.
- Иконка «Выйти» в шапке: высота +4 (30 → 34), решение владельца.
- Попапы: заголовок без изменения (15), ширина до 440 px (верхняя граница).
- Заголовок пустой зоны (дропзона): без изменения (14).
- Кнопка входа Google: без изменения (50 px).
